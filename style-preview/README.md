# Portfolio style study

Run the existing Vite dev server and open `/style-preview/`. The Quiet,
Editorial, and Studio buttons update `?style=` so a direction can be bookmarked.
This English-language comparison reuses project and article data, but has its
own entry point and CSS. It is intentionally excluded from the production build.

The main portfolio's Autonoma icon is a local copy of the official organization
avatar from https://github.com/Autonoma-AI.png, retrieved November 13, 2026.
